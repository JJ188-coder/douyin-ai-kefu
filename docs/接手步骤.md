# 新电脑接手步骤（从克隆到插件跑起来）

> 目标：在另一台 Mac 上把「抖音来客 AI 客服插件」跑起来，配置（人设/知识库/API Key）和这边完全一致。
> 克隆命令：`git clone git@github.com:JJ188-coder/douyin-kefu-ai.git`（默认分支 full-snapshot = 完整镜像，含全部环境）

## 0. 先回答两个最常见的问题

- **克隆下来会自动打开浏览器、自动装插件吗？** 不会。Chrome 插件必须手动在 chrome://extensions 里加载一次（下面的第 2 步），这一步任何工具都替代不了（谷歌的安全限制）。
- **人设和知识库跟着仓库走吗？** 不直接跟。它们存在浏览器的插件本地存储里，不在代码里。仓库里带了两份保险：① `docs/handover-config.json`（配置导出件 + 一键恢复脚本）；② `reverse/chrome-profile-plug/`（这边调试 Chrome 的完整 profile，含登录态和配置，可直接用）。

## 1. 装依赖

- 安装 Chrome
- 安装 Node.js（18+ 即可）

## 2. 装插件（一次性，约 1 分钟）

1. Chrome 地址栏打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择克隆目录下的 `plugin/` 文件夹
4. 看到「抖音来客 AI 人工接管助手 v0.3.7」即成功

## 3. 恢复配置（人设/知识库/API Key/飞书推送）

两条路任选：

**路线 A（推荐，干净）**：用导出件恢复

```bash
# 先以调试模式启动 Chrome（user-data-dir 换个新路径就是全新浏览器）
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9223 --user-data-dir=/tmp/aics-chrome-profile &
# 在 chrome://extensions 完成第 2 步的加载，然后点一下插件图标让 popup 打开过一次
node reverse/cdp/restore-config.mjs
# 看到 OK {"written":17,"kb":37,"hasKey":true,"profile":true} 即恢复完成
```

**路线 B（连登录态一起搬）**：直接用打包进来的浏览器 profile

```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9223 \
  --user-data-dir=<克隆目录>/reverse/chrome-profile-plug &
```

这个 profile 里有：插件配置（37 条知识库、人设、API Key）+ 抖音来客的登录态。
注意：插件安装路径在这台电脑上写的是 `/Users/jiyuanyi/Documents/抖音客服/plugin`，如果克隆路径不同，Chrome 会提示插件「已损坏/找不到」——点修复重新指到克隆目录的 `plugin/` 即可，配置不会丢（配置存在 profile 里，不认路径）。

## 4. 验证

1. 打开抖音来客客服台 `https://life.douyin.com/cs/web` 并登录（路线 B 可跳过，登录态已带）
2. 点插件图标：开关=开、自动发送=开、知识库 37 条、人设有内容
3. 跑测试确认环境没问题：

```bash
cd <克隆目录>
for t in plugin/tests/*.test.mjs; do node "$t" | tail -1; done
# 全部显示 ALL PASS 即正常（26+ 项）
```

## 5. 日常开发约定（重要）

- 代码改动一律开任务分支：`codex/YYYY-MM-DD-简述`，**不要直接在 main 上改**
- 合并回 main 前跑全部测试；合并由人发话（说"合并"）
- 版本号唯一可信源：`plugin/manifest.json`
- 插件改完代码后要重载才生效：`node plugin/reload-ext.mjs`（需要 Chrome 以 9223 调试模式开着）
- 架构/策略/门禁说明都在 `README.md`；原理一页图：`docs/插件原理图.html`（浏览器打开）
